# LeetCode Tracker MCP

MCP-сервер для отслеживания прогресса на LeetCode: статистика, серии, цели, заметки и интервальные повторения.

## Установка

Нужен Node.js 20 или новее.

```bash
npm install
npm run build
```

## Подключение

Claude Code (подставьте свой username и абсолютный путь к проекту):

```bash
claude mcp add leetcode-tracker --env LEETCODE_USERNAME=your_username -- node "C:/path/to/leetcode-tracker-mcp/dist/index.js"
```

Claude Desktop и другие MCP-клиенты:

```json
{
  "mcpServers": {
    "leetcode-tracker": {
      "command": "node",
      "args": ["C:/path/to/leetcode-tracker-mcp/dist/index.js"],
      "env": { "LEETCODE_USERNAME": "your_username" }
    }
  }
}
```

## Настройки

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `LEETCODE_USERNAME` | Нет | Username по умолчанию |
| `LEETCODE_TRACKER_DATA` | Нет | Путь к файлу данных, по умолчанию `~/.leetcode-tracker/data.json` |
| `LEETCODE_SESSION` | Нет | Cookie сессии, нужна только для импорта всей истории |
| `LEETCODE_CSRF_TOKEN` | Нет | Cookie `csrftoken`, используется вместе с сессией |

Cookie `LEETCODE_SESSION` даёт полный доступ к аккаунту. Не добавляйте её в git и не публикуйте конфиг с ней.

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `sync_progress` | Импортирует решения с LeetCode и сохраняет снимок прогресса за день |
| `get_progress` | Показывает решённые задачи, рейтинг, серию, прирост за 7 и 30 дней, цели |
| `log_attempt` | Записывает попытку, время, уверенность 1–5 и заметку |
| `get_problem_history` | Показывает историю попыток по задаче |
| `list_tracked_problems` | Фильтрует задачи по статусу, сложности и теме |
| `get_due_reviews` | Показывает задачи, которые пора повторить |
| `analyze_topics` | Находит слабые и малопрактикованные темы |
| `set_goal` | Задаёт цель по числу решённых задач и дедлайн |
| `get_daily_challenge` | Показывает задачу дня |

## Примеры запросов

- «Синхронизируй мой прогресс на LeetCode и покажи, что изменилось за неделю»
- «Запиши: two-sum решил за 12 минут, уверенность 4, использовал хеш-таблицу»
- «Что мне сегодня повторить?»
- «Поставь цель 300 medium к 1 июня и посчитай нужный темп»
- «Какие темы у меня самые слабые?»

## Как работают повторения

| Уверенность | Следующий интервал |
| --- | --- |
| 1–2 | 1 день |
| 3 | Текущий × 1,5, минимум 2 дня |
| 4 | Текущий × 2,5, минимум 4 дня |
| 5 | Текущий × 3,5, минимум 7 дней |

Максимальный интервал равен 180 дням. Решения старше 14 дней импортируются в историю, но не попадают в очередь повторений.

## Ограничения

- Без сессии LeetCode отдаёт только 20 последних принятых решений, поэтому синхронизируйте прогресс регулярно.
- Сервер использует неофициальный API LeetCode, который может измениться без предупреждения.
- Дни считаются по UTC, как и на LeetCode.
